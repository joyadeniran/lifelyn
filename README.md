# Lifelyn

The access & revenue-cycle layer for Africa's healthcare providers.

## Overview

Lifelyn (www.trylifelyn.com) is building the infrastructure for African healthcare providers to capture every patient request, keep every appointment, and ensure every claim is paid.

### Key Value Propositions

- **EMR-agnostic**: Works with any hospital system.
- **Offline-first**: Built for the Nigerian power and connectivity reality.
- **HMO-native**: Real-time eligibility checks and claim packaging.
- **Data moat**: Proprietary access dataset for every request.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Lucide React](https://lucide.dev/) for icons
- **Deployment**: [Vercel](https://vercel.com/)

## Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/joyadeniran/lifelyn.git
   cd lifelyn
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router pages and global styles.
- `components/`: Reusable React components (Landing page sections, etc.).
- `public/`: Static assets (images, icons, etc.).
